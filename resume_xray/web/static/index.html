          How it works
          
    
            
      
          1. Your file is read three ways, the way common ATS text extractors read it: in the order it is stored, top to bottom across the page, and column by column.
            2. 
      
          2. Checks compare those readings and report what gets lost, scrambled or split, and in which kind of reader.
            3. 
      
          3. Keyword matching asks one question: would a recruiter's search with the job's own words find you? Other word forms and synonyms get half credit.
            4. 
      
          4. There is no single "ATS score", because no ATS publishes one. Every rule, threshold and source is documented in ALGORITHM.md in the repository.
            5. 
    
          
    
          Everything runs on your computer. The page cannot connect to any other address, no data is stored, and no AI model is used.
